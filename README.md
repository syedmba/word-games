## 🕹️ Currently Implemented Games

Take your pick from our growing arcade of terminal classics:

*   🟩 **Wordle** — Guess the hidden word before you run out of tries!
*   💀 **Hangman** — The classic letter-guessing survival game.
*   🔴 **Connect Four** — Drop your tokens and connect four in a row.
*   👽 **Imposter** — Can you find the fake among you?

---

## ⚙️ How to Launch

In your terminal, simply run the following command to launch the respective game.

```bash
bash launch.sh imposter
# Options: `wordle`, `hangman`, `connectfour`, `imposter`
```

This script handles the path and logging config properly.
